# Node.js Cheatsheet

A structured learning resource for understanding **Node.js and backend development with JavaScript**. This repository organizes important concepts into topic-wise Markdown files, making it useful for students, beginners, and developers who want a quick reference.

## 📚 Topics Covered

| No. | Topic | Description |
|---|---|---|
| 01 | Node.js Basics | Runtime fundamentals and executing JavaScript |
| 02 | npm | Package management and dependencies |
| 03 | Modules | Organizing and reusing code |
| 04 | File System | Reading, writing, and managing files |
| 05 | Events | Event-driven programming and EventEmitter |
| 06 | HTTP | Creating HTTP servers and handling requests |
| 07 | Express.js | Routing, middleware, and web applications |
| 08 | Async/Await | Asynchronous programming |
| 09 | Error Handling | Managing errors and rejected promises |
| 10 | Environment Variables | Managing application configuration |
| 11 | REST APIs | Designing and building API endpoints |
| 12 | MongoDB | Database integration concepts |
| 13 | Authentication | User authentication fundamentals |
| 14 | Project Structure | Organizing maintainable Node.js applications |

## 🛠️ Prerequisites

- Basic knowledge of JavaScript
- Node.js installed on your system
- npm, included with standard Node.js installations
- Visual Studio Code or another code editor

Verify your installation:

```bash
node --version
npm --version
```

## 🚀 Getting Started

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/nodejs-cheatsheet.git
```

### Step 2: Open the Project

```bash
cd nodejs-cheatsheet
code .
```

### Step 3: Start Learning

Open the numbered Markdown files in sequence. Read each concept, try the code examples in a practice project, and modify them to understand how they work.

## 💡 Recommended Learning Path

1. **Fundamentals:** Node.js basics, npm, and modules.
2. **Core Features:** File system operations, events, and HTTP.
3. **Web Development:** Express.js, routing, and middleware.
4. **Asynchronous Programming:** Promises, async/await, and error handling.
5. **Backend Configuration:** Environment variables and project organization.
6. **API Development:** REST APIs, MongoDB, and authentication.

## 🎯 Learning Objectives

- Understand how Node.js executes JavaScript outside the browser.
- Manage dependencies using npm.
- Work with modules, files, events, and HTTP servers.
- Build web applications with Express.js.
- Write asynchronous code and handle errors effectively.
- Understand API development, database integration, and authentication.
- Organize backend projects using maintainable practices.
